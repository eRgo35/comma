# comma Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `comma` binary plus bash Enter hook that turns `,<plain English>` lines into a reviewable command on the prompt line, or a short printed answer.

**Architecture:** A bash hook (embedded in the binary, printed by `comma init bash`) intercepts Enter. On a `,` line it calls `comma ask "<raw text>"` and acts on the exit code: 0 = command on stdout → put on prompt line; 2 = answer already printed → clear line; anything else = error already printed → keep line. The Rust side builds a prompt, calls the Anthropic API (falling back to `claude -p`), and parses a JSON reply. All per-session state (previous request/command) lives in bash variables, passed to the binary via env vars — no files.

**Tech Stack:** Rust (edition 2024), `ureq` 3, `serde_json` 1, bash 5 readline.

**Spec:** `docs/superpowers/specs/2026-11-04-comma-design.md`

## Global Constraints

- Binary/package name: `comma`. Prefix: `,` at column 0.
- Dependencies: only `ureq = "3"` and `serde_json = "1"`. Nothing else without asking the user.
- Model: `claude-haiku-5-5`. Key: env `ANTHROPIC_API_KEY`. No config file, no flags beyond the two subcommands.
- API endpoint `https://api.anthropic.com/v1/messages`, headers `x-api-key`, `anthropic-version: 2023-06-01`, `content-type: application/json`. Global timeout 5s.
- Fallback to `claude -p` only on missing key or HTTP error status — never on network error/timeout.
- Context sent: cwd, OS, nu availability, request, previous request + command. Never file names or shell history.
- Human-facing output (spinner, warnings, answers, errors) → stderr. Only the generated command → stdout.
- Exit codes of `comma ask`: `0` command, `2` answer, `1` error.
- Generated commands are never executed by comma — the user presses Enter.

## Review Focus

1. Requests containing `'`, `"`, `$`, backticks, `>` , `|` — must reach the binary byte-for-byte and never be `eval`ed. (Task 4 test `raw_text_passed_verbatim`.)
2. Error on a `,` line must NOT fall through to `accept-line`, or bash runs `,foo` → "command not found". (Task 4 test `error_keeps_line_and_blocks_accept`.)
3. Bare `,` or `,   ` — no API call, line unchanged, not executed. (Task 4 test `empty_request_does_nothing`.)
4. Model wraps JSON in ```json fences or adds prose — fenced JSON accepted; garbage → clean error, line kept. (Task 1 tests `parses_fenced_json`, `rejects_garbage`.)
5. `nu` not installed — model must be told so it never emits `nu -c`. (Task 2 test `user_message_reports_nu_absent`.)

### Task 4: CLI and bash hook

**Files:**
- Create: `src/hook.bash`, `tests/hook.rs`, `tests/cli.rs`
- Modify: `src/main.rs`

**Interfaces:**
- Consumes: `prompt::{gather_context, user_message, SYSTEM_PROMPT}`, `backend::complete`, `reply::{parse_reply, Reply}`.
- Produces (CLI contract):
  - `comma init bash` → prints `include_str!("hook.bash")`, exit 0.
  - `comma ask <request>` → spinner `thinking…` on stderr (only if stderr is a TTY; cleared with `\r\x1b[2K`); then
    `Command` → optional `⚠ <warning>` on stderr, command on stdout, exit 0;
    `Answer` → text on stderr, exit 2;
    any error → `comma: <msg>` on stderr, exit 1.
  - anything else → usage line on stderr, exit 1.
- Produces (bash): function `__comma_process` (pure logic, testable without readline) and `__comma_hook` (wrapper that does the binding trick). Shell vars `__COMMA_PREV_REQUEST`, `__COMMA_PREV_COMMAND`, `__COMMA_HANDLED`.

**Hook design (`src/hook.bash`):**

```bash
__comma_process() {
  __COMMA_HANDLED=0
  [[ $READLINE_LINE == ,* ]] || return 0
  __COMMA_HANDLED=1
  local req="${READLINE_LINE#,}" out rc
  [[ -n ${req//[[:space:]]/} ]] || return 0
  history -s -- "$READLINE_LINE"
  out=$(COMMA_PREV_REQUEST="$__COMMA_PREV_REQUEST" COMMA_PREV_COMMAND="$__COMMA_PREV_COMMAND" \
        command comma ask "$req"); rc=$?
  case $rc in
    0) READLINE_LINE=$out; READLINE_POINT=${#out}
       __COMMA_PREV_REQUEST=$req; __COMMA_PREV_COMMAND=$out ;;
    2) READLINE_LINE=; READLINE_POINT=0
       __COMMA_PREV_REQUEST=$req; __COMMA_PREV_COMMAND= ;;
  esac   # any other rc: line left as typed
}
__comma_hook() {
  __comma_process
  if (( __COMMA_HANDLED )); then bind '"\C-x\C-a": redraw-current-line'
  else bind '"\C-x\C-a": accept-line'; fi
}
if [[ $- == *i* ]] && command -v comma >/dev/null; then
  bind -x '"\C-x\C-c": __comma_hook'
  bind '"\C-x\C-a": accept-line'
  bind '"\C-m": "\C-x\C-c\C-x\C-a"'
fi
```

(Enter runs the hook, then whatever `\C-x\C-a` was just rebound to: `accept-line` for normal lines, a no-op redraw for `,` lines so the generated command waits for a second Enter.)
